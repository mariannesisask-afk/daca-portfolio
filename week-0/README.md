# Nädal 0 – Marianne Sisask

## Sellel nädalal

Sel nädalal seadistasin meie meeskonnale ühise GitHubi repo ning kutsusin kõik meeskonnaliikmed sinna collaborator'iteks.
Lisasin GitHubi üldise tutvustuse ja lisaks vajalikud kaustad iga nädala kohta, kuhu hakkame koondama iganädalasi dokumente (nädala README, nädala kokkuvõte + lisafailid).

Eraldi lisasin Team Charter faili, kus on kajastatud meeskonna kokkulepped.

Omavaheliseks suhtlemiseks lõin Google Chatis meeskonnale eraldi grupi.


## Õppisin

Õppisin seadistama järgmisi keskkondi:

- Supabase
- GitHub
- Python 
- VS Code


## AI kasutamine

Kasutasin AI abi peamiselt selleks, et veenduda korrektses seadistamises. 
Palusin AI käest ka täpsustavaid selgitusi erinevate funktsioonide kohta, lisaks sain abi Markdown tekstide loomisel,
GitHubis mittetöötavate linkide muutmisel ja mitmetes teistes operatiivsetes küsimustes.


## Minu Week 0 väljundid

Minu töö tulemusena on:

- loodud meeskonna ühine GitHubi repo;
- loodud portfoolio README.md fail, kuhu on lisatud meeskonna tutvustus, nädala rollid, rollide rotatsioon ja kõikide loodud keskkondade lingid;
- kõik meeskonnaliikmed on collaborator'id;
- olemas GitHub struktuur ja vajalikud kaustad iga nädala kohta;
- lisatud eraldi Team Charter fail meeskonna kokkulepetega;
- loodud meeskonna Google Chat grupp igapäevaseks suhtluskanaliks
