# Week 3 — INNER JOIN ja LEFT JOIN

## Minu roll

**Müügikanalid + Kliendid (INNER JOIN + mitme tabeli JOIN)**

Minu vastutus Week 3 jooksul on analüüsida müügikanalite efektiivsust:

- uurida müügikanaleid sales tabelis;
- anda kanalite põhiülevaade;
- ühendada sales ja customers — klientide profiil kanali kaupa;
- ühenda 3 tabelit: sales + customers + products;
- leida kõige efektiivsem kanal (müük per klient);
- kirjuta müügikanalite analüüs
